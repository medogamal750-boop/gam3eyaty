# نظام إدارة الجمعيات المالية (Gam3eyaty)

نظام إلكتروني متكامل لإدارة ومتابعة الجمعيات الشهرية والمشتركين والأقساط، مع كشوف حسابات تفاعلية، ولوحة تحكم للمدير، ومزامنة سحابية مدعومة بـ Google Firebase.

## الملفات الأساسية:
- `index.html`: واجهة النظام وبوابة المشتركين ولوحة المدير.
- `style.css`: التنسيقات والتصميم الزجاجي العصري (Glassmorphism).
- `app.js`: المحرك البرمجي والحسابات وإدارة النوافذ.
- `data.js`: البيانات والجمعيات الأولية.
- `firebase-config.js`: إعدادات الربط مع Google Firebase.
- `firebase-service.js`: خدمات السحابة والمصادقة وقاعدة البيانات Firestore.
